BUILDLAB STATIC PORTFOLIO — GITHUB PAGES

1. Upload the contents of this folder to your GitHub repository.
2. In GitHub, open Settings > Pages and publish from your main branch/root folder.
3. Projects on index.html are hard-coded and work on GitHub Pages. The Add Project page uses browser localStorage and is only a local-browser manager; additions made there do not publish to GitHub Pages. Edit index.html to add permanent projects.
4. Replace sample SVG files in assets/ and assets/projects/ with your real screenshots. Keep filenames the same or update the image paths in index.html.
5. Put a real documentation.pdf in each project folder if you want the PDF link to work.
6. Before publishing, replace your.email@example.com in index.html and script.js with your actual contact email.

The included SVGs are placeholders to prevent broken images; they are not actual screenshots of your software.
